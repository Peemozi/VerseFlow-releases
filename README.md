# VerseFlow AI Releases

This repository contains official release builds and update files for VerseFlow AI.

It is used by the VerseFlow in-app updater to distribute new versions of the application.

## Contents

Releases may include:

- VerseFlow Windows installer
- Auto-update metadata
- Blockmap files
- Release notes
